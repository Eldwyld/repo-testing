# Discord History Tracker – standalone userscript

An unofficial, browser-only build of [Discord History Tracker](https://github.com/chylex/Discord-History-Tracker) (DHT) that runs entirely inside **Violentmonkey**. You don't need the desktop app.

Current versions of DHT send everything to the desktop app. The official `dht.user.js` userscript only loads the tracking script from the running app. This build uses the tracking code from **DHT v47.4** (January 2026), the latest upstream release. It keeps tracked messages in the browser tab and saves them as a file in the archive format of the old browser-only version.

The file you get can be:

- opened in [`viewer.html`](viewer.html), which is the old browser-only viewer and works offline, or
- imported into the desktop app later (**Database → Import Legacy Archive**).

## Install

1. Install [Violentmonkey](https://violentmonkey.github.io/).
2. Open the raw [`discord-history-tracker.user.js`](discord-history-tracker.user.js) file. Violentmonkey shows its install page. Click **Install**.
   - Alternatively, in the Violentmonkey dashboard click **+ → New**, replace the template with the file's contents, and save.
3. Reload Discord in the browser.

Tampermonkey will probably work too, because the script uses `@grant none`, but it hasn't been tested there.

## Use

1. On discord.com, click the new **DHT** icon next to the **Help** (?) icon in the top bar.
   - If Discord changes its layout and the icon can't be placed there, a floating **DHT** button appears in the bottom-right corner after about 15 seconds.
2. A bar appears at the bottom of the page. The settings dialog opens on first use.
3. Open a channel or DM and click **Start Tracking**. With autoscroll on, DHT scrolls up until it reaches the first message. Depending on settings, it then pauses or moves on to the next channel.
4. Click **Download** to save the archive as a `.txt` file (JSON).
5. Later, click **Upload & Combine** to load an earlier archive and continue adding to it. This also makes the setting *"After reaching a previously saved message…"* work across sessions.

| Button | What it does |
|---|---|
| Upload & Combine | Merges one or more previously downloaded archives into the current session |
| Settings | Autoscroll, hiding previews, and what to do at the first or a previously saved message |
| Start / Pause Tracking | Toggles tracking of the currently open channel |
| Download | Saves everything tracked so far |
| Reset | Clears the current session |
| X | Closes the tracker |

> **Tracked messages exist only in this browser tab until you click Download.** If you try to close the tracker, close the tab, or reload Discord with messages that haven't been downloaded, the script asks you to confirm first.

## Limitations compared to the desktop app

- **No attachment downloads.** The archive stores only the attachment URLs. Discord's CDN links expire, so images in old archives may stop loading. Use the desktop app if you need attachments saved.
- The legacy archive format has fewer fields. It stores usernames (not display names) and does not record which thread belongs to which channel.
- Memory use grows with the size of the archive, because it is held in the tab and serialized when downloaded. For very large archives, use the desktop app.
- This build depends on Discord internals the same way the official script does. When Discord changes those internals, it breaks until the tracking code is updated (see below).

## Updating and building

`discord-history-tracker.user.js` is generated by `build.py` from the files in `src/`:

| File | Origin |
|---|---|
| `src/scripts/discord.js`, `webpack.js`, `dom.js`, `settings.js`, `types.js` | Copied unchanged from upstream `app/Resources/Tracker/scripts/` (v47.4) |
| `src/scripts/state.js` | New. Stores data in memory instead of sending it to the desktop app |
| `src/scripts/savefile.js` | From the browser-only branch (v.31h), updated for current Discord message objects |
| `src/scripts/gui.js`, `src/bootstrap.js`, `src/styles/*.css` | From upstream v47.4, with the Upload/Download/Reset controls of the browser-only version |
| `src/userscript.js` | Userscript header and DHT launch button, based on upstream `dht.user.js` |
| `viewer.html` | Copied unchanged from the browser-only branch build (`bld/viewer.html`, v.31h) |

When upstream releases a fix for a Discord update, copy the changed files from `app/Resources/Tracker/scripts/` into `src/scripts/`. Do not copy `state.js` or `gui.js`. Then bump `VERSION` in `build.py` and run:

```sh
python3 build.py
```
